02
PKG

Create the Python Package

PACKAGE LAYER
+

Turn the project into an importable package so components can communicate cleanly instead of relying on notebook cells.

components/ → data_ingestion.py • data_transformation.py • model_trainer.py
pipeline/ → training.py • prediction.py
utils/ → logger.py • exception.py
config/ → paths and project configuration
03
DATA

Data Ingestion

COMPONENT 01
+
InputRaw diamond dataset containing carat, cut, color, clarity, depth, table, x, y, z and price.
ProcessRead the source data, validate it and prepare it for the ML workflow.
OutputTrain/test data artifacts ready for downstream transformation.
Raw CSV → DataIngestion → train.csv + test.csv
04
SPLIT

Train / Test Split

VALIDATION BOUNDARY
+
Training setUsed to fit preprocessing and machine-learning models.
Test setHeld back to estimate how the trained system performs on unseen data.
Key ruleFit transformations on training data; apply the fitted transformation to test/new data.
05
PRE

Data Transformation

COMPONENT 02
+
Numerical featuresMissing-value handling and scaling where required.
Categorical featuresEncode cut, color and clarity into model-compatible numerical representations.
PreprocessorBuild one reusable preprocessing object so training and prediction use the same transformation logic.
X_train → fit_transform()
X_test / new input → transform()

Saved as: artifacts/preprocessor.pkl
06
ML

Model Training & Best Model Selection

COMPONENT 03
+
TrainTrain candidate regression algorithms on the transformed training data.
EvaluateCompare candidates using regression metrics such as R², MAE and RMSE.
SelectChoose the best-performing model according to the evaluation strategy.
Candidate models → Train → Evaluate → Best Model
Best model → artifacts/model.pkl
07
RUN

Training Pipeline — training.py

ORCHESTRATOR
+

Instead of manually running every component, training.py triggers the complete training workflow in sequence.

training.py
↓
Data Ingestion
↓
Train/Test Split
↓
Data Transformation
↓
Save preprocessor.pkl
↓
Model Training + Evaluation
↓
Save model.pkl
↓
TRAINING COMPLETE
08
API

Prediction Pipeline

prediction.py
+
Load artifactsLoad the persisted preprocessor and trained model.
Transform inputConvert incoming diamond characteristics using the same preprocessing fitted during training.
PredictPass transformed features into the trained regression model and return the estimated price.
User Input → preprocessor.pkl → transformed features → model.pkl → predicted price
09
WEB

Flask Application + Templates

APPLICATION LAYER
+
FrontendHTML templates render the input form and prediction result.
BackendFlask receives form data, validates/constructs the input and calls the prediction pipeline.
ResponseThe predicted diamond price is rendered back into the template.

Flask route

Prediction Pipeline
↓
preprocessor.pkl + model.pkl

10
DKR

Dockerize the Application

CONTAINERIZATION
+
DockerfileDefine the Python runtime, dependencies, application files and startup command.
BuildCreate a reproducible image containing Flask + ML code + required runtime dependencies.
RunRun the same image locally before pushing it to AWS.
docker build -t diamond-price-prediction .
docker run -p 8080:8080 diamond-price-prediction
11
ECR

Push Docker Image to Amazon ECR

CONTAINER REGISTRY
+
RepositoryCreate an Amazon ECR repository for the application image.
AuthenticateAuthenticate Docker with the AWS ECR registry.
PushTag and push the image so ECS can pull the deployable artifact.
Local Docker Image
↓
ECR Repository
↓
Versioned Container Image

ECS

CLOUD RUNTIME
+

ServiceRun the container as an ECS service and keep the desired number of tasks running.
